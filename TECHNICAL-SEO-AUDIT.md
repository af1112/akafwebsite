## Additional verified release blockers

- First rendered regression run: 51/57 route checks passed; Features lacked H1 and Digital Menu had two H1s in all three locales. Semantic heading variants were implemented afterward; the final rebuild and 96/96 rendered regression confirmed the H1 corrections.
- Internal-link crawl found /en/forgot-password, /fa/forgot-password and /ar/forgot-password returning 404. No reset flow was invented and no unrelated redirect was substituted. Owner/product team must supply or approve the recovery destination.
- Anonymous unknown routes in EN/FA/AR returned real HTTP 404, not 200 soft-404 pages.
- `npm audit --omit=dev --audit-level=high` returned 8 production dependency findings: 4 moderate, 3 high, 1 critical. Next 14.2.33 is among flagged packages; this is package advisory evidence, not a verified exploit against this deployment. Do not release without triage and a separately tested supported upgrade. No `audit fix --force` or security-policy bypass was run.
- No configured third-party MCP account access was available for Search Console, Bing, GA4 or hosting verification.
