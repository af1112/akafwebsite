PC Software Source Code

This directory contains the Django backend for the Project Control Software.

Status: The source code is available here (static files).

How to Run this App

To execute this application (Django Backend), you must deploy it as a separate project on Vercel:

  1. Go to Vercel Dashboard > Add New Project.
  2. Import the akafwebsite repository.
  3. In "Root Directory" settings, specify: public/pc_software.
  4. Deploy.

Once deployed, you will get a new URL (e.g., pc-software.vercel.app) where the Django app will be running.
